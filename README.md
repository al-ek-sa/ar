# Лабораторная работа №4. Эксперимент

Транслятор ассемблера, компоновщик и потактовая модель RISC-процессора с гарвардской архитектурой, системой прерываний и кешем.

- Лишик Александра Юрьевна, P3206
- Вариант: `asm | risc | harv | hw | trap | mem | cstr | cache | alg2`

| Особенность | Значение |
| --- | --- |
| Язык | `asm`: ассемблер с метками, секциями, `.org`, макросами и раздельной трансляцией |
| Архитектура | `risc`: команды фиксированной длины, load/store |
| Память | `harv`: раздельные память команд и память данных, байтовая адресация |
| Control Unit | `hw`: hardwired |
| Ввод-вывод | `trap`: через систему прерываний |
| Ввод-вывод ISA | `mem`: memory-mapped |
| Строки | `cstr`: null-terminated |
| Усложнение | `cache`: кеш памяти данных |
| Алгоритмы | `alg2`: `collatz_length`, `infix_to_rpn` |

## Структура репозитория

```text
.
├── isa.py              # система команд, кодирование и декодирование

├── linker.py           # компоновщик: объектные модули -> бинарный образ

└── docs/               # схемы DataPath и ControlUnit
```

## Язык программирования

### Синтаксис

```ebnf
program        ::= { line }
line           ::= [ label ] [ statement ] [ comment ] "\n"
label          ::= identifier ":"
statement      ::= instruction | directive | macro_call
instruction    ::= mnemonic [ operand { "," operand } ]
operand        ::= register | immediate | identifier | offset "(" register ")"
directive      ::= "." identifier [ argument { "," argument } ]
comment        ::= ";" { any_char }
```

### Директивы

| Директива | Назначение |
| --- | --- |
| `.text` / `.data` | переключение секции |
| `.org addr` | размещение следующего кода или данных с адреса `addr` |
| `.byte` / `.word` | статические данные, строки |
| `.equ name, value` | константа времени трансляции |
| `.global name` / `.extern name` | экспорт и импорт символов |
| `.macro` / `.endm` | макроопределение |
| `.if` / `.else` / `.endif` | условная компиляция |

## Тестирование

Тестирование выполняется golden-тестами: каждый тест хранится в одном YAML-файле в каталоге `golden/` и содержит исходный код, машинный код с мнемониками, ввод, вывод и журнал работы процессора.

| Алгоритм | Тест |
| --- | --- |
| hello | `golden/hello.yml` |
| cat | `golden/cat.yml` |
| hello_user_name | `golden/hello_user_name.yml` |
| sort | `golden/sort.yml` |
| арифметика двойной точности | `golden/double_precision.yml` |
| collatz_length | `golden/collatz_length.yml` |
| infix_to_rpn | `golden/infix_to_rpn.yml` |
| раздельная трансляция | `golden/linking.yml` |
| работа кеша | `golden/linear_filter.yml` |
