# Лабораторная работа №4. Эксперимент

- Лишик Александра Юрьевна, P3206
- Вариант: `asm | risc | harv | hw | trap | mem | cstr | cache | alg2`

Транслятор ассемблера с макросами и раздельной трансляцией, компоновщик и модель процессора с точностью до такта. Процессор RISC с системой команд RV32I/RV32M (подмножество) и 16 регистрами RV32E, гарвардской архитектурой, вводом через прерывания, портами ввода-вывода в памяти и кешем памяти данных.

| Особенность | Вариант | Реализация |
| --- | --- | --- |
| Язык | `asm` | ассемблер: метки, секции `.text`/`.data`, `.org`, макросы, константы, условная компиляция, раздельная трансляция и компоновка |
| Архитектура | `risc` | команды по 32 бита, load/store, кодирование по спецификации RISC-V |
| Память | `harv` | раздельные память команд и память данных по 4 КиБ, байтовая адресация |
| Control Unit | `hw` | hardwired: комбинационная логика и счётчик шагов |
| Ввод-вывод | `trap` | ввод по прерываниям с расписанием символов, вывод посимвольно |
| Ввод-вывод ISA | `mem` | порты отображены на адреса `0x80`, `0x84`, `0x88` |
| Строки | `cstr` | строки с завершающим нулём |
| Усложнение | `cache` | двухканальный кеш с обратной записью: 1 такт кеш, 10 тактов память |
| Алгоритмы | `alg2` | `collatz_length`, `infix_to_rpn` |

## Организация памяти

| Параметр | Значение |
| --- | --- |
| Машинное слово | 32 бита, порядок байт little-endian |
| Адресация | байтовая, слово выровнено на 4 |
| Память команд | 4 КиБ, однопортовая, только чтение во время работы |
| Память данных | 4 КиБ, однопортовая, слова (`lw`/`sw`) и байты (`lbu`/`sb`), доступ через кеш |
| Регистры | 16 регистров общего назначения по 32 бита (`x0 = 0`), `PC`, `EPC` |

```text
            Registers                         Instruction memory
+-------------------------------+     +----------------------------------+
| x0  zero   всегда 0           |     | 0x000 : j _start   вектор сброса |
| x1  ra     адрес возврата     |     | 0x004 : j isr      вектор        |
| x2  sp     указатель стека    |     |                    прерывания    |
| x3  gp, x4 tp  не используются|     | 0x008 : код программы            |
| x5..x7    t0..t2  временные   |     |   ...                            |
| x8..x9    s0..s1  сохраняемые |     |         процедуры модулей,       |
| x10..x15  a0..a5  аргументы   |     |         обработчик прерывания    |
+-------------------------------+     |   ...                            |
| PC, EPC, IR, AR, WR           |     | 0xFFC                            |
| IE, in_irq  флаги CU          |     +----------------------------------+
+-------------------------------+

                    Data memory
+----------------------------------------------+
| 0x000 ... 0x0FF : порты ввода-вывода, не память, мимо кеша
|   0x080 : порт ввода (чтение)                |
|   0x084 : порт вывода (запись)               |
|   0x088 : счётчик тактов (чтение)            |
| 0x100 : данные первого модуля (.data)        |
|   ...   данные следующих модулей             |
|   ...   свободно                             |
|   ...   стек, растёт вниз                    |
| 0xFFF   STACK_TOP = 0x1000                   |
+----------------------------------------------+
```
